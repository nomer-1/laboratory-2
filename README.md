Мета роботи: навчитися використовувати основні принципи ООП, відзначити конструкцію побудови класу та створення об’єктів та навчитися працювати з ними.

class — команда для створення класу.



MyName — назва нашого класу.
total_names = 0 — змінна класу, яка рахує кількість створених об'єктів.
Текст у потрійних лапках """ """ — документація, тобто опис класу.
__init__ — конструктор, який запускається автоматично під час створення об'єкта.
self — посилання на конкретний об'єкт.
name=None — ім'я може бути відсутнім.
self.name — зберігає ім'я конкретного об'єкта.
MyName.total_names += 1 — збільшує загальний лічильник на одиницю.
self.my_id — присвоює об'єкту його номер.
Bohdan → Bohdan
Marta → Marta
None → Anonymous
@classmethod — позначає метод класу.
cls — посилання на сам клас.
cls("Anonymous") — створює новий об'єкт із іменем Anonymous.
all_names — це словник, у якому ключами є початкові імена, а значеннями — створені об'єкти.
me — сам об'єкт.
me.name — ім'я.
me.my_id — номер об'єкта.
me.whoami — повідомлення з ім'ям.
me.my_email — електронна адреса.
type() — визначає тип об'єкта або методу.
